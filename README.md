# Rajeev Manick — Research Portfolio

A responsive static academic/research portfolio built with HTML, CSS and a small amount of JavaScript. No build step or framework is required.

## Publish with GitHub Pages

1. Upload the contents of this folder to the root of the repository.
2. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Commit changes and wait for the Pages deployment workflow to complete.

## Files

- `index.html` — main portfolio
- `styles.css` — visual system and responsive layout
- `script.js` — navigation and footer year
- `projects/sgan.html` — semi-supervised learning project
- `projects/young-stars.html` — young stars and CI Tau discovery
- `assets/favicon.svg` — data-network favicon
