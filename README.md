# Rajeev Manick — Research Portfolio (v2)

A responsive, static academic portfolio built with HTML, CSS and vanilla JavaScript. No build step or framework is required.

## Files
- `index.html` — main portfolio
- `styles.css` — responsive visual system and layout
- `script.js` — mobile navigation and dynamic footer year
- `projects/` — individual project pages for BICEPs, SGAN and young-star research
- `assets/favicon.svg` — site icon

## Deploy on GitHub Pages
1. Download and extract the ZIP.
2. Open your GitHub repository (`rajeevzar.github.io`).
3. Replace the existing `index.html`, `styles.css`, `script.js` and `README.md` with the files in this folder.
4. Upload the `projects` and `assets` folders, preserving their structure.
5. Commit the changes to the `main` branch.
6. GitHub Pages should deploy automatically. Check the Actions tab if needed.

## Before publishing
- Confirm current institutional title and affiliation wording.
- Add a current professional email address if you want it public.
- Add ORCID once the exact public profile URL is confirmed.
- Replace or add a current CV PDF only after updating the older CV.
- Check the Google Scholar and GitHub links.
- Add DOI links for newer publications and any accepted computational-biology papers.

## Notes on claims
Project pages describe research directions and reported experimental results. SGAN's approximately 93 ± 2% accuracy is explicitly scoped to the reported Mitocheck experiment (80 labelled images per class and 600 unlabelled images); it is not presented as a general benchmark.
