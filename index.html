01 / ABOUT

A CROSS-DISCIPLINARY PATH

One scientific
mindset. Many scales.

My scientific career began in astrophysics, investigating the evolution and binarity of evolved stars. More recently, I have expanded my work into machine learning and computational biology, applying data-driven approaches to microscopy and cellular phenotyping.

The common thread is quantitative discovery: understanding how complex systems evolve, separating signal from noise, and building methods that remain interpretable and useful beyond a single dataset.

01 / COMPUTATIONAL MICROSCOPYMETHOD DEVELOPMENT

BICEPs

An interpretable, feature-based pipeline for cell-phase classification. BICEPs combines engineered image descriptors, statistical feature selection and neighbourhood-based classification to investigate how far transparent, data-efficient methods can go in cellular phenotyping.

SGAN for smart microscopy

A semi-supervised generative adversarial network designed to reduce annotation requirements for cell-cycle classification. The work explores how a small labelled set can be combined with unlabelled microscopy images.
